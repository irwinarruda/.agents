# Irwin Style

1. **Local skills win.** If a project-scoped skill covers the area, use it and skip the data files.
2. **No local styleguide skill? Reading the styleguide is REQUIRED for coding tasks.** Before writing or editing code, read the relevant data file — this is not optional:
   - `data/code-guide.md` — formatting, types, functions, naming, imports, comments.
   - `data/react-guide.md` — React/JSX, event handlers, state (Zustand/MobX).
   - `data/personality.md` — optional private context; read only when it exists and tone or priorities genuinely need calibration. Never recreate it from the public example or conversation history.
3. **Keep it current.** If Irwin corrects a style choice or states a lasting preference, propose the exact edit. Skip one-offs; keep the files lean.
